# Kalkulator Matematika Kelas 9 (aplikasi web)

Isi folder ini: index.html, manifest.webmanifest, sw.js, ikon (png dan svg).
Semua file harus ada di folder yang sama.

## Cara pasang di GitHub Pages (gratis)
1. Buat akun di github.com, lalu buat repository baru, misalnya `kalkulator-mtk9`, atur ke Public.
2. Klik Add file > Upload files, tarik semua file dari folder ini, lalu Commit.
3. Buka Settings > Pages. Di Source pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.
4. Tunggu 1-2 menit. Alamatnya: https://NAMAKAMU.github.io/kalkulator-mtk9/

## Cara pasang di HP
- Android (Chrome): buka alamat di atas, ketuk menu titik tiga, pilih Instal aplikasi.
- iPhone (Safari): ketuk Bagikan, pilih Tambah ke Layar Utama.
Setelah dibuka sekali dengan internet, aplikasi bisa dipakai tanpa internet.

## Alternatif: Netlify
Buka app.netlify.com/drop, tarik seluruh folder ini ke halaman itu, selesai.
